## 📋 Architectural Spec: Native Tool-Calling & Dynamic Dispatch System

**Component ID:** STRATA-SPEC-003  
**Status:** PROPOSED

---

### 1. System Overview & The Serialization Challenge

Large Language Models (LLMs) do not invoke system code directly; they output structured JSON containing a function name and an array of arguments (e.g., `{"name": "get_stock_level", "arguments": {"sku": "A100-80G"}}`).

Traditional AI frameworks handle this by forcing developers to manually write separate JSON-Schema definitions matching their native code functions, or by using heavy reflection at runtime. This causes clear system fragilities:

- **Schema Drift:** Modifying a variable name or type parameter in a native backend function without manually updating the corresponding string-based JSON-Schema schema string leads to silent runtime parsing exceptions.
- **Performance Penalties:** Utilizing heavy reflection paths inside high-frequency loop systems drops performance and completely breaks Ahead-of-Time (AOT) compiler trimming profiles.

Datalium Strata resolves this using compile-time meta-programming: Procedural Macros in Rust and Roslyn Source Generators in C#. Developers annotate standard native methods, and the compiler automatically outputs JSON-Schema declaration payloads and generates high-efficiency strongly-typed function dispatch blocks.

---

### 2. Metaprogramming and Dispatch Flow Pipeline

```text
[ Developer Code ] ──► (Annotated Function Method)
                               │
                        (Compiler Step)
                               ├──► [ Auto-Generates JSON-Schema Manifest ]
                               └──► [ Builds Static Typed Dispatch Tables ]

[ Runtime Flow ]   ──► (LLM JSON Tool Request)
                               │
                (Zero-Reflection Fast Invocation)
                               ▼
                 [ Direct Memory Native Execution ]
```

### 3. C# Tool-Calling Architecture (Datalium.Strata.SourceGenerators)

In .NET, we leverage Roslyn Source Generators. Instead of looking up functions at runtime using reflection, the compiler generates a static, lock-free dispatch partial method that maps incoming text blocks directly onto strongly-typed method invocations.

#### Developer Code Interface

```csharp
using Datalium.Strata.Tools;

namespace EnterpriseAgent;

public partial class DatabaseTools
{
    [StrataTool(Name = "read_user_balance", Description = "Fetches the current ledger balance for a user ID.")]
    public static async Task<decimal> GetUserBalanceAsync(int userId, string currency = "USD")
    {
        // Native optimized DB logic
        return await Task.FromResult(1500.50m);
    }
}
```

#### Auto-Generated Compiler Output (Hidden Source Code generated by Strata)

```csharp
// <auto-generated />
namespace EnterpriseAgent;

public partial class DatabaseTools : IStrataToolProvider
{
    // 1. Static JSON Schema compiled directly into the binary assembly memory
    public string GetToolsManifest() => """
    [
      {
        "name": "read_user_balance",
        "description": "Fetches the current ledger balance for a user ID.",
        "parameters": {
          "type": "object",
          "properties": {
            "userId": { "type": "integer" },
            "currency": { "type": "string", "default": "USD" }
          },
          "required": ["userId"]
        }
      }
    ]
    """;

    // 2. Direct static invocation map (Zero reflection used, full AOT trimming safe)
    public async Task<string> DispatchToolAsync(string toolName, string jsonArguments)
    {
        if (toolName == "read_user_balance")
        {
            var args = System.Text.Json.JsonSerializer.Deserialize<UserBalanceArgs>(jsonArguments);
            decimal result = await GetUserBalanceAsync(args.userId, args.currency);
            return $"{{\"balance\": {result}}}";
        }
        throw new ToolNotFoundException(toolName);
    }

    private record UserBalanceArgs(int userId, string currency);
}
```

### 4. Rust Tool-Calling Architecture (datalium-strata-macros)

In Rust, we utilize Procedural Attribute Macros (derive processing). This generates an implementation of a `StrataTool` trait, allowing static dispatch using array slices at hardware-level speeds.

#### Developer Crate Layout

```Rust
use datalium_strata::prelude::*;
use serde::Deserialize;

// 1. Structural arguments layout with automatic JSON conversion mapping
#[derive(Deserialize, StrataSchema)]
pub struct InventoryArgs {
    pub sku: String,
    pub warehouse_id: u32,
}

// 2. Wrap function attachment using attribute triggers
#[strata_tool(name = "check_inventory", description = "Query warehouse item quantities.")]
pub async fn check_inventory(args: InventoryArgs) -> Result<String, ToolError> {
    Ok(format!("SKU {} count is 42 in Zone {}", args.sku, args.warehouse_id))
}
```

#### Under the Hood: Macro Code Generation Target

```Rust
// Code emitted automatically by macro expansion during cargo build
impl StrataTool for check_inventory {
    fn schema(&self) -> serde_json::Value {
        serde_json::json!({
            "name": "check_inventory",
            "description": "Query warehouse item quantities.",
            "parameters": {
                "type": "object",
                "properties": {
                    "sku": { "type": "string" },
                    "warehouse_id": { "type": "integer" }
                },
                "required": ["sku", "warehouse_id"]
            }
        })
    }

    fn execute<'a>(&self, raw_args: &'a str) -> Pin<Box<dyn Future<Output = Result<String, StrataError>> + Send + 'a>> {
        Box::pin(async move {
            let parsed_args: InventoryArgs = serde_json::from_str(raw_args)
                .map_err(|_| StrataError::ToolArgumentParseFailure)?;

            // Inline static call invocation path
            let output = check_inventory(parsed_args).await
                .map_err(|_| StrataError::ToolExecutionFailure)?;
            Ok(output)
        })
    }
}
```

### 5. Cross-Language Edge Cases & Mitigations

- **Type Safety for Union and Optional Variables:** Dynamic environments pass `None` or `null` values fluidly, which frequently breaks strict, typed parameter layouts in native functions.
    - **Mitigation:** Strata's code generation engines inspect method metadata types directly. Optional variables (such as C# nullable types `string?` or Rust `Option<T>`) are automatically flagged as optional fields inside the produced JSON-Schema specifications, setting fallback default inputs natively if parameter blocks are missing from LLM outputs.
- **Sandbox Security & Execution Timeout Tracking:** AI systems can fall into recursive tool-calling cycles or execute slow external network routines that lock processing pipelines.
    - **Mitigation:** Tool execution tasks are wrapped in a monitored system frame context. Developers can assign granular time limits to tool calls at the graph config level:

```csharp
// Set a hard 2-second timeout ceiling for external API actions
graph.SetToolTimeout(TimeSpan.FromSeconds(2));
```
